# CSE206 Digital Logic Design Sessional

**Credits:** 1.50 | **Hours per week:** 3

## Topics Covered

- Boolean algebra and logic gates
- Combinational logic circuits (arithmetic and data handling)
- Decoders, encoders, multiplexers, and demultiplexers
- Flip-flops and latches
- Sequential circuits (asynchronous and synchronous)
- State diagrams and state minimization
- Registers and counters
- Memory systems (RAM and ROM)
- Programmable logic arrays (PLA)
- **4-bit ALU design and implementation**
