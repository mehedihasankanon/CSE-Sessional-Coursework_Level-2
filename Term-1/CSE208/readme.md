# CSE208 Data Structures and Algorithms II Sessional

**Credits:** 1.50 | **Hours per week:** 3

## Topics Covered

- Graph algorithms (minimum spanning tree, shortest path)
- Maximum flow and bipartite matching
- Balanced binary search trees (AVL, red-black, splay trees)
- Skip lists
- Advanced heap structures (Fibonacci heaps, binomial heaps)
- Hashing techniques
- NP-completeness and NP-hard problems
- Backtracking and branch-and-bound algorithms
- Approximation algorithms
- String matching algorithms
