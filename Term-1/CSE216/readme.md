# CSE216 Database Sessional

**Credits:** 1.50 | **Hours per week:** 3

## Topics Covered

- Relational database model
- Entity-Relationship (ER) model and database design
- SQL query language
- Relational algebra
- Constraints, functions, procedures, and triggers
- Functional dependencies and normalization
- Indexing (primary, secondary, B+ tree, hash indices)
- Query processing and optimization
- Transaction management and concurrency control
- Recovery systems
- Introduction to parallel and distributed databases
- Big data analytics and NoSQL databases
- **Database project work**
