# EEE264 Electronic Circuits Sessional

**Credits:** 1.50 | **Hours per week:** 3

## Topics Covered

- Diode characteristics and applications
- Bipolar Junction Transistor (BJT) circuits
- MOSFET circuits
- Wave shaping circuits (clipping and clamping)
- Comparator and switching circuits
- BJT and MOSFET amplifiers
- Operational amplifiers (Op-amps)
- Linear applications of Op-amps
- Oscillators and timers (555 timer)
- Function generators
