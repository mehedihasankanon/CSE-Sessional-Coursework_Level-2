# Level 2 Term 1 Sessional Courses

Coursework:

## CSE206 Digital Logic Design Sessional

- 3 hours/week, 1.50 credits
- Practical sessions based on digital logic design, including 4-bit ALU design and implementation.

## CSE208 Data Structures and Algorithms II Sessional

- 3 hours/week, 1.50 credits
- Lab work focused on advanced data structures and algorithms.

## CSE216 Database Sessional

- 3 hours/week, 1.50 credits
- Practical database design and implementation, including a project based on database concepts (in a different GH repo).

## EEE264 Electronic Circuits Sessional

- 3 hours/week, 1.50 credits
- Laboratory sessions covering electronic circuits and applications.
