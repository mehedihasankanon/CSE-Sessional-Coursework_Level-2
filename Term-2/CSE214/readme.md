# CSE214 Software Engineering Sessional

**Credits:** 0.75 | **Hours per week:** 3 (in alternate weeks)

## Topics Covered

- Sessional based on CSE 213 (Software Engineering theory)
- Use case modeling and documentation
- UML diagram creation and interpretation
- Design pattern implementation
- Software testing practices (unit, integration, system testing)
- Software documentation and technical writing
- Version control and Git workflows
- Code review and collaboration techniques

## Practical Assignments

- Use case analysis and documentation
- UML modeling for real-world systems
- Design pattern implementation
- Test case design and execution
- Version control exercises
- Code review simulations
