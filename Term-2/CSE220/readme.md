# CSE220 Signals and Linear Systems Sessional

**Credits:** 1.50 | **Hours per week:** 3

## Topics Covered

- Sessional based on CSE 219 (Signals and Linear Systems theory)
- Continuous and discrete-time signal processing
- Linear Time Invariant (LTI) systems analysis
- Convolutional operations and system properties
- Fourier analysis and transforms in practice
- Sampling and interpolation implementation
- Laplace transform applications
- Z-transform for discrete systems
- Time and frequency domain analysis

## Practical Laboratory Work

- Signal generation and visualization
- Convolution operations
- Fourier analysis experiments
- Filter design and implementation
- Sampling and aliasing demonstrations
- System characterization and analysis
- MATLAB/Python programming for signal processing
