# Level 2 Term 2 Courses

## Theory Courses

### CSE 200 Technical Writing and Presentation

- 3 hours in alternate weeks, 0.75 credits
- Issues of technical writing and effective oral presentation in Computer Science and Engineering
- Writing styles for definitions, propositions, theorems, and proofs
- Preparation of reports, research papers, theses: abstract, preface, contents, bibliography, and index
- Writing of book reviews and referee reports
- Writing tools: LaTeX, etc.; Diagram drawing software; presentation tools

### CSE 209 Computer Architecture

- 3 hours in a week, 3.00 credits
- Information representation and computer performance measurement
- Instruction set architectures: MIPS/ARM, operations and operands
- Computer Arithmetics: Integer and floating-point operations
- Processor design: single-cycle datapath, pipelined datapath, hazards, exceptions
- Instruction-Level Parallelism: multiple issue, speculation, superscalar, dynamic pipelining
- Memory organization: cache, cache optimization, virtual memory
- Multiprocessors: SISD, MIMD, SIMD, SPMD, vector architectures
- Parallel architectures: data-level parallelism, GPU architecture

### CSE 213 Software Engineering

- 3 hours in a week, 3.00 credits
- Professional software development and ethics
- Software development life cycle (SDLC)
- Requirements analysis: functional/non-functional requirements, use cases, validation
- System modeling and design: UML diagrams, UI design
- Design patterns: creational, structural, behavioral
- Development: code review, documentation, version control, code refactoring
- Testing and debugging: unit testing, integration testing, performance/security testing

### CSE 219 Signals and Linear Systems

- 3 hours in a week, 3.00 credits
- Signals and systems: continuous/discrete-time signals, LTI systems
- Time domain analysis: differential and difference equations
- Frequency domain analysis: Fourier series and transforms
- Sampling theorem, interpolation, aliasing
- Laplace and Z-transforms
- Analysis and characterization of LTI systems

## Sessional Courses

### CSE 200 Technical Writing and Presentation Sessional

- No dedicated sessional; integrated with theory course

### CSE 210 Computer Architecture Sessional

- 3 hours in alternate weeks, 0.75 credits
- Practical sessions based on CSE 209
- Assignments and project work: Booth Multiplier Design, Microprocessor Design, FPGA programming

### CSE 214 Software Engineering Sessional

- 3 hours in alternate weeks, 0.75 credits
- Practical sessions based on CSE 213
- Topics: use cases, UML, design patterns, testing, documentation, version control

### CSE 220 Signals and Linear Systems Sessional

- 3 hours in a week, 1.50 credits
- Practical sessions based on CSE 219
- Lab assignments and experiments with signals and systems
